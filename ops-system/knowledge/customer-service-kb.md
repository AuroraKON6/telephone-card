# 电话卡娘智能客服知识库

## 首轮接待

你好，我是电话卡娘。你可以告诉我所在地区、年龄段、每月预算、想要多少流量、是否需要选号，我先帮你判断适合看哪类套餐。

## 咨询收集字段

- 所在省市区
- 收货地址是否完整
- 年龄段
- 每月预算
- 运营商偏好
- 是否需要选号
- 是否接受首充
- 用途：刷视频、游戏、办公、家人副卡、热点共享

## 常见问答

### 流量卡是否正规

页面展示的是正规运营商号卡推广信息。具体套餐、归属地、禁发区、年龄限制、首充规则，以 172 后台商品详情和运营商审核结果为准。

### 为什么会审核失败

常见原因包括年龄不符、一证多号、收货地址不完整、高风险地区、黑名单、短期重复下单等。建议下单前先确认地区和身份名下号码情况。

### 首充为什么重要

部分套餐需要按指定金额和指定渠道完成首充，才能享受赠费、优惠或返佣。不同产品规则不同，必须看后台商品详情。

### 能否选号

部分产品支持选号。若套餐支持选号，后续接入 172 选号接口后可以先选择号码，再下单；不支持选号的套餐不承诺号码。

### 订单状态怎么查

后续接入 172 回调后，可以根据平台订单号同步“已提运营商、已发货、已完成、已撤单、已取消、审核不通过”等状态。当前未接 API 时需要人工后台查询。
