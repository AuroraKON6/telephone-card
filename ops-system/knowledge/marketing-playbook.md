# 172 号卡营销运营手册

## 内容方向

- 省钱场景：月底流量不够、刷视频多、经常开热点、给家人办副卡。
- 规则透明：先讲地区、年龄、首充、激活和禁发区，减少售后误解。
- 轻种草：强调“先咨询再办理”，避免夸张承诺。
- 私域承接：从公开内容引导到合规咨询，不诱导绕过平台交易。

## 常用内容结构

1. 场景开头：你是不是每个月流量都不够用。
2. 需求筛选：地区、年龄、预算、流量需求。
3. 套餐展示：用可替换字段展示月租、流量、通话、首充规则。
4. 风险提示：禁发区、审核、首充渠道。
5. 承接问题：评论或私信留下地区和预算。

## 审批前检查

- 是否使用绝对化词。
- 是否承诺审核必过。
- 是否遗漏首充和禁发区提示。
- 是否虚构“官方授权”。
- 是否有诱导短期注销或规避规则。
- 是否需要人工确认套餐真实性。
