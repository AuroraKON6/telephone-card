# 电话卡娘官网前端原型

## 功能

- 蓝白金二次元通信视觉。
- 使用 `public/assets/mascot-hero.png` 作为首屏看板娘，`mascot-reference.png` 保留原始角色设定图。
- 热门流量套餐可点击切换。
- 页面中段有滚动驱动的 3D SIM 卡翻转。
- 动态背景光标追踪、信号粒子、看板娘悬浮、按钮扫光、滚动进度条和数据流动画。
- 本地客服对话演示、快捷问题、FAQ 折叠。
- 咨询表单占位，后续可接真实订单或私域咨询链路。

## 启动

```powershell
npm install
npm run dev -- --port 5173
```

## 构建

```powershell
npm run build
```

生成目录：`dist/`。
